# hr-kpi-dashboard

HR and recruiting KPI dashboard built from operational data at Bafing S.A.C., Lima (2021–2025).

At Bafing I owned the full HR reporting cycle — Power BI dashboards tracking 8 departmental KPIs, monthly compliance reports for CEO and Board, and recruitment tracking across 4 concurrent hospital infrastructure projects. This dashboard reproduces that reporting structure with simulated data.

**Live:** [andresribla1-art.github.io/hr-kpi-dashboard/dashboard.html](https://andresribla1-art.github.io/hr-kpi-dashboard/dashboard.html)

---

**What it tracks**

- Departmental KPI compliance across 8 areas (SOC, NOC, HR, ISO, Training, Recruitment, Workforce Planning, Project Delivery)
- Recruitment activity for 4 hospital infrastructure projects — 47 roles filled over 3 years
- Core HR metrics: time-to-hire, retention rate, payroll accuracy, training completion

**Stack:** HTML · CSS · no dependencies
